# 資料型卡帶（風格包 JSON）

使用者不需要重新建置，就能把**自己的風格包**放進這個工具：一份 JSON 檔，沒有任何程式碼。

## 怎麼用

- **匯入**：面板「風格・場景層・後製」→ **📥 匯入風格包（.json）**（可一次選多個檔）。匯入後出現在風格包選單，用法和內建的一樣。
- **匯出**：先把畫面調成喜歡的樣子 → **📤 把目前設定存成風格包** → 輸入名稱 → 下載 JSON。只會存「和出廠預設不同」的設定，不含節拍、偏移等跟這首歌有關的設定。
- **移除**：選單「移除我匯入的風格包…」。內建風格包不能移除。
- **保存位置**：這台瀏覽器的本機儲存（localStorage，鍵 `klpacks`）。換瀏覽器或清除網站資料就沒了，請保留 JSON 檔。離線渲染不讀這份儲存（專案檔本來就帶完整設定）。

## 格式

見 [`examples/pack.example.json`](../examples/pack.example.json)。

| 欄位 | 必填 | 說明 |
|---|---|---|
| `kind` | ✅ | 固定 `"pack"` |
| `apiVersion` | ✅ | 固定 `1` |
| `label.zh` | ✅ | 風格包名稱，1～24 字，不可含 `< > " ' \` \` |
| `author` `license` |  | 60 字內文字 |
| `config` | ✅ | 設定鍵值；鍵必須是面板上有的設定（同內建風格包用的鍵），值只能是文字、數字或 true／false |

## 安全規則（程式強制）

- 只收 JSON 資料，**不執行任何程式**；多餘的欄位、未知的設定鍵、物件／陣列值、過長文字、`presetName`、`__proto__` 一律拒絕。
- 單檔上限 16 KB；自己匯入的風格包最多 40 個；與內建風格包同名會被拒絕（自己匯入的同名會被取代）。
- 找不到的場景名、版型名、字體只給警告並略過，不會壞掉。

## 給開發者

- 實作：`core/api/data-carts.js`（`UserPacks`）；登記走 `Console.cart(d, { user: true })`，與內建卡帶同一條路，且 `user` 卡帶只能是 `pack`。
- 測試：`node test/data-pack.mjs`。
- 版型、特效等會執行程式的卡帶，目前仍只能經 PR 進 `carts/`（見 `docs/architecture-plan.md` 第 7 節）。
